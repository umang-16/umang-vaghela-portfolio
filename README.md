## ✨ Features

- **🎨 Premium UI/UX Design:** Stunning dark/light mode functionality built with CSS variables, featuring high-end glassmorphism panels, gradients, and soft shadows.
- **🎬 Cinematic Preloader:** A visually engaging startup loading screen with an animated glowing logo, progress bar, and typing text that seamlessly fades into the website.
- **📱 Fully Responsive:** Carefully structured using Flexbox and Grid layouts to ensure a flawless experience across Mobile, Tablet, and Desktop screens.
- **✉️ Real-Time Email System:** Fully functioning Contact Form powered by EmailJS, completely integrated with asynchronous JS, timeout fallbacks, loading spinners, and beautiful toast notifications.
- **⚡ Performance Optimized:** Lightweight Vanilla JS and pure CSS architecture—no bulky frameworks—ensuring blazing fast load speeds.
- **🪄 Smooth Animations:** Scroll-reveal staggered animations, floating background orbs, animated statistics counters, and micro-interactions on hover.

## 🚀 Getting Started

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/umang-16/umang-vaghela-portfolio.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd umang-vaghela-portfolio
   ```

3. **Open `index.html` in your browser:**
   Double-click the `index.html` file or use an extension like **Live Server** in VS Code for live reloading.

## 📬 Contact Setup (EmailJS)

The contact form is configured to send emails directly to the inbox without a backend server using EmailJS. 

To configure it for yourself:
1. Create a free account at [EmailJS](https://www.emailjs.com/).
2. Add a new Email Service (e.g., Gmail).
3. Create an Email Template using variables: `{{from_name}}`, `{{reply_to}}`, `{{phone_number}}`, `{{subject}}`, and `{{message}}`.
4. Replace the existing `Public Key`, `Service ID`, and `Template ID` inside `index.html` and `script.js` with your own.
